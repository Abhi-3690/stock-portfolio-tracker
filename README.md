# 📊 Stock Portfolio Tracker

A simple Python-based Stock Portfolio Tracker that calculates the total investment value of manually selected stocks.

The program uses predefined stock prices and allows the user to enter stock symbols and quantities. It calculates the investment for each stock and the total portfolio value.

## ✨ Features

- 📈 Predefined stock price dictionary
- 🔤 User enters stock symbols
- 🔢 User enters stock quantity
- 💰 Calculates investment for each stock
- 💵 Calculates total investment value
- ⚠️ Handles invalid stock symbols
- ⚠️ Handles invalid quantities
- 📄 Exports portfolio details to CSV
- 🧹 Organized using Python functions

## 🛠️ Technologies Used

- Python
- Dictionary
- Functions
- Lists
- CSV module
- File handling
- Input/Output
- Basic arithmetic
